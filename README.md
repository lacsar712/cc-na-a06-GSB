# 航标灯光巡检台

登记航标实测光强和方位偏差，服务端当场给出合格或不合格。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

顶栏“方位分档”按方位偏差的绝对值把实测分进三档（小偏角 / 中偏角 / 大偏角）：

- 两道档界由持灯账号 keeper 在现场页保存，分档计算在服务端完成。
- 现场页给出每档条数，可点进该档查看灯号列表。
- 持灯账号可签发分档快照：签发时冻结当时两道档界、每档条数和成员主键。事后改档界只影响现场页，旧快照正文不变。
- 只读账号 watch 只能查看现场页和快照，不能改档界、不能签发（直接 POST 也会被拒绝）。

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格。
2. 再登记一条光强低于要求的记录，结论为光强不足。
3. 换 watch 登录，没有登记入口；直接提交登记会拒绝。
4. 顶栏进入“方位分档”：keeper 把两道档界改成 0.3 和 1 并保存，明亮种子 BR-01（0.4 度）落在中间档，现场页中间档可点进灯号列表看到 BR-01。
5. 仍用 keeper 签发一份分档快照，记下编号；快照正文中间档成员含 BR-01。
6. 把档界改宽（如 1 和 3），现场页 BR-01 回到小偏角档；再打开刚才那份快照，中间档成员仍含 BR-01，档界与条数不变。
7. 换 watch 登录“方位分档”：只能查看现场页与快照，没有改档界和签发入口；直接 POST 会拒绝。
