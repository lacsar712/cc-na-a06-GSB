# 航标灯光巡检台

登记航标实测光强和方位偏差，服务端当场给出合格或不合格。页面由 Django 模板直接渲染，浏览器不另跑一套单页应用。

方位分档（顶栏「方位分档」）按方位偏差绝对值把实测分进小/中/大三档，分档计算在服务端。持灯账号 keeper 可保存两道档界、签发分档快照；只读账号 watch 只能查看现场页和快照。快照签发时冻结当时两道档界、每档条数与成员主键，事后改宽档界只影响现场页，旧快照正文不变。

## 端口

|------|------|

| 应用 | http://localhost:8190 |

## 启动

```bash
cd projects/11-nav-aid-inspection
docker compose up --build
```

## 验收

1. 打开 http://localhost:3190 ，用 keeper 登录，列表里 LH-01 合格、LH-09 不合格。
2. 再登记一条光强低于要求的记录，结论为光强不足。
3. 换 watch 登录，没有登记入口；直接提交登记会拒绝。
4. 顶栏「方位分档」：keeper 把两道档界保存为 0.3 和 1，明亮种子 LH-01 的 0.4 度落入中间档，点「签发分档快照」留存。
5. 再把档界改宽（如 0.5 和 2），打开刚才那份快照：冻结档界仍为 0.3/1，中间档成员仍含 LH-01；而现场页中间档已随之变空。
6. 用 watch 打开现场页看不到改档界表单与签发按钮；直接 POST 改档界或签发均返回 403。
